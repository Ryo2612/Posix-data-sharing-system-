# Posix-data-sharing-system
A local data - sharing system developed in C using POSIX standards, demonstrating process management, inter-process communication(IPC), and low level systems-programming. Technical documentation is stored above.

## Key Features 

- Process creation
- IPC communication
- client/server architecture
- POSIX system calls
- Multi-process communication

## Technologies
- C
- POSIC
- LINUX/UNIX
- GCC
- Make
